# OOP Assignments 🚀

This repository contains my solutions for the **Object-Oriented Programming (OOP)** course assignments at **Pamukkale University**.

## 📌 Overview
The project focuses on implementing core OOP principles using **Java**. Currently, it includes geometric implementations that demonstrate:
* **Classes & Objects:** Defining custom data types.
* **Encapsulation:** Using private fields and public getters/setters.
* **Composition:** Building complex objects (like `Line` and `PolyLine`) using simpler ones (`Point`).
* **Constructors:** Overloading and initializing object states.

## 📂 Project Structure
* `Point.java`: Represents a point in a 2D coordinate system.
* `Line.java`: Represents a line segment defined by two points.
* `PolyLine.java`: A collection of points forming a multi-segment line.
